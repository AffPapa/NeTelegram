# NeTelegram

NeTelegram — нативный клиент для macOS на Swift и AppKit с TDLib. Проект находится в разработке; публичного установщика пока нет.

## Состояние

Исходник включает вход через номер телефона, код, пароль 2FA и QR, список и историю чатов, отправку текста и одного фото, темы форумов, поиск, раздельные черновики, системные уведомления и блокировку интерфейса через LocalAuthentication. Это описание реализации в исходнике, а не заявление о полном тестировании: реальный аккаунт ещё не прошёл сквозную проверку, а запуск 20 авторизованных профилей и измерения производительности не сертифицированы.

Текущая версия сайта не предлагает скачивание приложения. Ссылка появится только после проверенной сборки, Developer ID подписи, нотарификации и проверки установки.

## Сборка и тесты

Нужны Xcode и Swift 6 или совместимый toolchain. Проектная цель — macOS 14+ и Apple Silicon.

```sh
swift test
Scripts/dev-app.sh --launch
```

Сначала соберите закреплённую TDLib через `Scripts/build-tdlib.sh`. Скрипт запуска всегда использует один development bundle и каталог данных; он откажется заменять работающий процесс. Инструкции и проверки исходников находятся в `Scripts/build-tdlib.sh` и `TDLIB.lock.json`.

## Вклад и безопасность

Перед изменениями прочитайте [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md), `PRODUCT-ARCHITECTURE.txt` и `ACCEPTANCE.json`. Не прикладывайте номера телефонов, коды входа, пароли, Telegram DB/files, ключи Keychain или необработанные диагностические логи. MIT распространяется только на новый код проекта; сторонние условия перечислены в `NOTICE`.
