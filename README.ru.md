# NeTide для macOS

[Русский](README.ru.md) · [English](README.md)

**NeTide** (кодовое имя репозитория — **NeTelegram**) — отдельное приложение для macOS на Swift и AppKit, которое разрабатывается для работы с облачными чатами Telegram через закреплённую версию TDLib. Если вы ищете альтернативный клиент Telegram для Mac, нативный клиент Telegram для macOS или проект клиента Telegram с открытым исходным кодом, здесь опубликованы исходники, фактический статус и ограничения разработки.

> **Независимый проект.** NeTide не является официальным приложением Telegram, не разработан Telegram и не имеет прямого отношения, одобрения или аффилиации с Telegram Messenger LLP. Названия Telegram и TDLib используются для описания совместимости и принадлежат их правообладателям. NeTide использует Telegram API/TDLib; это отдельный клиент экосистемы Telegram, а не отдельная сеть обмена сообщениями.

> **Статус:** разработка продолжается. Подписанной установочной сборки для скачивания нет. Реальный вход, отправка сообщений с аккаунтом пользователя и проверка двадцати одновременно авторизованных аккаунтов пока не подтверждены. Публичная страница загрузок: [netelegram.iryadom.chatgpt.site](https://netelegram.iryadom.chatgpt.site/).

Они описывают тему проекта, не означают одобрение Telegram и не являются данными о поисковой частотности.

## Что реализуется

Архитектура проекта использует Swift, AppKit и TDLib 1.8.68 с закреплёнными исходниками и схемой. В исходниках предусмотрены отдельные профили и хранилища аккаунтов, обычный вход через Telegram, runtime нескольких аккаунтов, чаты и сообщения, текстовый путь, фотографии, локальные черновики, системные уведомления и блокировка интерфейса. Эти пункты описывают код и план продукта, а не подтверждённую готовность пользовательских сценариев.

Целевой сценарий — поддерживать подключённые аккаунты в фоне, пока приложение запущено, Mac не спит и сеть доступна; выбранный интерфейс показывает один аккаунт, не выгружая остальные. Матрица 1/5/10/20 реальных аккаунтов, память и производительность пока не сертифицированы. Сессии Telegram Desktop и других клиентов не импортируются. Секреты входа и коды подтверждения не следует присылать в issues или хранить в исходниках.

## Функции и ограничения

Планируются облачные личные и групповые чаты, чтение каналов после закрытия требований совместимости, текст и ссылки, ответы, темы, редактирование и удаление в пределах прав, раздельные черновики, фотографии с подписями, входящие альбомы, поиск, уведомления каждого аккаунта, повторная авторизация, выход, локальная privacy-блокировка, клавиатура и VoiceOver. Входящий неподдерживаемый тип должен сохранять контекст в понятной карточке.

В v1 не входят звонки, voice chats, запись или воспроизведение аудио, обычный видеоплеер, GIF-анимация, наборы и picker стикеров, emoji picker, конструктор реакций, Stories, Mini Apps runtime, AI/переводчик, кошелёк, платежи, CRM, рассылки, автоответы, универсальная отправка документов и перенос чужих сессий. Каналы доступны только для чтения в утверждённом плане; фактический доступ отложен.

## Совместимость и публичное название

Используемый поисковый язык — «неофициальный клиент Telegram для macOS», «альтернативный клиент Telegram для Mac» и “unofficial Telegram client for macOS”. Это описательные формулировки, а не обещание официальности, рейтинга или измеренного спроса. Объёмы запросов и позиции сайта не измерялись.

Действующие [условия Telegram API](https://core.telegram.org/api/terms) ограничивают название приложения: §2.3 допускает слово “Telegram” в заголовке только если перед ним стоит “Unofficial”. Выбранное публичное название — NeTide; NeTelegram остаётся кодовым именем репозитория. Это не решает отдельные требования §1.3/1.4 к базовой функциональности и §3.3 к sponsored media. §2.2 также требует заметно сообщать, что приложение использует Telegram API и входит в экосистему Telegram. Доступ к каналам отложен; совместимость API не заявляется.

## Разработка

Цель проекта — macOS 14+ и Apple Silicon. Нужны Xcode и совместимый Swift toolchain. Сначала соберите закреплённую TDLib, настройте собственные допустимые данные Telegram API в защищённом Keychain flow, затем выполните:

```sh
swift test
Scripts/dev-app.sh --launch
```

Не используйте API credentials другого приложения и не переносите сессии чужих клиентов. См. [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md), [`PRODUCT-ARCHITECTURE.txt`](PRODUCT-ARCHITECTURE.txt) и [`NOTICE`](NOTICE).
