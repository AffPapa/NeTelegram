Независимый проект. Не приложение Telegram.

NeTelegram — независимый сторонний проект и не имеет прямого отношения к Telegram; Telegram Messenger LLP не разрабатывала и не одобряла приложение. Проект использует Telegram API и TDLib; совместимость публичного названия и отдельные требования API Terms ещё оцениваются.

ENGLISH OVERVIEW

A separate messaging workspace for Mac.

NeTelegram is an independent open-source project for a native macOS client to Telegram cloud chats. It is not the official Telegram app and has no direct relationship with Telegram Messenger LLP. Development is ongoing: real account login, twenty authorized background runtimes, and a signed download have not been verified.
